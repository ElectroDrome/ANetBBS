# ANetBBS v1.1.52 — fsxNet Last Caller timestamp fix (October 2026)

The pipe-delimited Last Caller wire format added in v1.1.51 carries a real timestamp from the originating BBS. Inbound posts in that format now use it as the row's own arrival time instead of the moment it was locally imported — previously, a batch of historical posts imported together in one sync run would all display the same "just now" timestamp rather than their real original times. The original fixed-field wire format is unaffected, since its own date/time fields are untrusted free text by design and were never used this way. A one-time data backfill for rows already imported under v1.1.51 is included separately — see the deploy notes.
