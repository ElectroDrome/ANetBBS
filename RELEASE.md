# ANetBBS v1.1.50 — Submenu renumbering fix for Door Games and File Areas (October 2026)

Fixes a bug in the admin "Renumber" button and drag-and-drop reordering for both Door Games and File Areas: games/areas inside a submenu category were being assigned a gapped `10/20/30/...` number sequence instead of a clean `1/2/3/...` one, contradicting the automatic every-boot numbering behavior those submenus already have — editing a submenu entry's number to `1` and clicking Renumber would see it immediately revert to `10`. Both admin tools now match the clean-numbering behavior submenu categories are supposed to have; top-level (non-submenu) numbering is unaffected.
