# ANetBBS v1.1.48 — Native MUD engine, door-games admin fixes, game-server mode, and DoorParty federation (October 2026)

The headline addition is **The Shattered Realm**, a complete native MUD built directly into ANetBBS (Game Center → Door Games) — four zones, four character classes (Warrior/Mage/Rogue/Cleric) with distinct abilities, a quest system, shops, a healer, live multiplayer chat, and real MUD telnet protocol support (MSSP/MCCP2/GMCP) for real MUD clients; a chain of bugs that together blocked playing it at all — a wrong "you need to be logged in" message, a database-access crash once that was fixed (on both the web UI and telnet/SSH), no visible echo while typing a name or class choice, and text breaking words apart at the edge of the screen — are also resolved. Alongside it: a long-standing Door Games bug where adding/removing/reordering any door silently renumbered every door listed after it is fixed, with new drag-and-drop reordering in the web admin for both games and their categories, and numbering collisions (most commonly a bulk-imported door network never individually numbered) now resolve themselves automatically on restart; file areas get the same category/submenu grouping treatment for the first time, with the same drag-and-drop admin and automatic numbering; a new standalone game-server deployment mode for running ANetBBS as a dedicated, game-only install over telnet/SSH/rlogin; and DoorParty door-network federation for bulk-importing shared multiplayer doors.
