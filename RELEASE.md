# ANetBBS v1.1.49 — Registration controls, docs access toggle, poll cleanup, and RSS/Who's Online settings (October 2026)

Registration can now be closed entirely or gated behind a shared invite code (configurable at Admin → Settings, default unchanged), enforced consistently across both the web form and the terminal registration flow; the built-in docs browser and new-sysop tutorial can now be restricted to admins only instead of being unconditionally public; admins can delete a poll outright rather than only closing it; Who's Online's IP display to admins now has a real on/off toggle; and RSS feed URLs are validated immediately on save, with a clear error for a missing or unsupported scheme instead of a silent failure at the next poll.
